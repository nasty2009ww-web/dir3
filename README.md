# Dir3 (درع) - الموقع الرسمي الرسمي لتطبيق أندرويد

الموقع الرسمي لتطبيق **درع (Dir3)** - مانع الإعلانات وحامي الخصوصية المتطور على مستوى نظام أندرويد.

> **شعار العلامة التجارية:** "تصفح بلا إعلانات، ولا متعقبين ولا احتيال"

---

## 🌟 نظرة عامة (Overview)

موقع ويب متكامل وفاخر مبني بأعلى معايير التصميم الحديثة لشركات الأمن السيبراني وتقنيات الـ SaaS العالمية (Pure Black + Dark Charcoal مع لمسات Neon Lime الخضراء `#D1FF42`).

### ✨ أبرز المزايا
- **تصميم عصري متقدم:** نمط Luxury Tech داكن مع مؤثرات توهج نيون وجدران حماية تفاعلية.
- **دعم كامل ومتقن للغة العربية (RTL First):** خط `Cairo` و `Plus Jakarta Sans` مع تناسق تام في الاتجاهات والمحاذاة.
- **محاكي هاتف ذكي تفاعلي (Interactive Phone Mockup):** تجربة حية تتيح للزائر تجربة تشغيل وإيقاف مفاتيح الحماية ومراقبة عداد الإعلانات الفوري.
- **قسم إحصائيات تفاعلي ومحدد بشفافية:** عدادات متحركة تعرض بيانات تجريبية توضيحية محددة بوضوح حتى توفر تقارير التطبيق الحية.
- **تنزيل حقيقي وقابل للتهيئة (Configurable APK Download):** إمكانية ضبط رابط الـ APK، رقم النسخة، الحجم، وبصمة التشفير `SHA-256` عبر ملف إعداد مركزي واحد.
- **أمان وخصوصية 100%:** شرح معماري مقارن لكيفية عمل الـ Local Loopback VPN على الجهاز بدون خوادم خارجية وسيطة.
- **أداء استثنائي (Zero Dependencies):** مبني بـ HTML5 / CSS3 / JavaScript النقية بدون مكتبات خارجية ثقيلة لتحقيق أعلى سرعة تحميل وأفضل معايير SEO.

## 📁 هيكلية المشروع (Project Structure)

```text
dir3/
├── index.html               # الصفحة الرئيسية الكاملة مع كامل الأقسام والنوافذ المنبثقة
├── css/
│   ├── style.css            # أنماط التصميم الفاخرة والتوافق مع الشاشات (Responsive)

│   ├── config.js            # ملف الإعدادات المركزي (رابط الـ APK، النسخة، الإحصائيات)
│   └── main.js              # السلوك التفاعلي، المحاكي، والعدادات والنوافذ
└── assets/
    ├── icons/               # أيقونات المتجهات
    └── images/
        └── hero-mockup.png  # لقطة الهاتف التوضيحية
```

## ⚙️ كيفية تخصيص وتعديل رابط التحميل والنسخة

يمكنك تعديل أي تفاصيل خاصة بالتطبيق في خطوة واحدة عبر فتح الملف:
`js/config.js`

```javascript
window.DIR3_CONFIG = {
  app: {
    name: "Dir3",
    arabicName: "درع",
    version: "v1.4.2",           // إصدار التطبيق
    releaseDate: "25 أكتوبر 2026", // تاريخ الإصدار
    fileSize: "18.4 ميجابايت",      // حجم ملف الـ APK
    sha256: "b79d86c4f31835e982...", // بصمة SHA-256
  },
  download: {
    // ضع هنا الرابط الرسمي المباشر لملف الـ APK الخاص بك
    apkUrl: "https://your-domain.com/downloads/Dir3-latest.apk",
  }
};
```

## 🚀 تشغيل الموقع محلياً (Local Preview)

يمكن فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيل خادم محلي خفيف:

```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js npx
npx serve .
```

افتح المتصفح على: `http://localhost:8080`
